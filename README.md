## 🌈 배경ㆍ문제 인식

요양원 선택 과정에서 정보가 흩어져 있어 시설 간 객관적인 비교가 어려움

공공 데이터는 존재하지만 일반 보호자가 이해·활용하기엔 진입장벽이 높음

비용, 위치, 돌봄 수준 등 개인 상황을 반영한 맞춤형 추천 서비스가 부족함

<br>

## 📝 프로젝트 개요

공공데이터와 사용자 입력 정보를 기반으로
보호자가 신뢰할 수 있는 요양원을 쉽고 투명하게 비교·추천받을 수 있는 플랫폼을 구축

<br>

## 🎯 핵심 가치

의사결정 지원: 데이터 기반 요양원 정보 제공으로 보호자의 선택 부담 완화

신뢰성 확보: 공공데이터 활용 및 추천 기준 공개를 통한 정보 투명성 강화

접근성 향상: 누구나 쉽게 이용 가능한 웹 서비스로 정보 격차 해소

<br>

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✅ **요양기관 예상 월 비용** | 상세한 시설 비용 계산으로 쉽게 예측 가능 |
| ✅ **지도 검색** | 지도를 통해 원하는 지역의 요양원을 한눈에 확인 |
| ✅ **검색 필터링** | 원하는 요양기관의 조건들을 필터링하여 확인 |
| ✅ **AI 맞춤 추천** | 요양기관의 특징을 입력해 요양원 추천 |
| ✅ **상세 요양원 정보** | 입소인원, 직원, 프로그램 등을 확인 |
| ✅ **요양원 관리** | 인증받은 요양원 운영자의 공지, 문의, 리뷰 관리 |
| ✅ **커뮤니티** | 요양원 사용자들의 질문글, 리뷰 등을 확인 |
